# Cloud-Native EKS Auto-Scaling Platform

## Project Overview

Cloud-Native EKS Auto-Scaling Platform is an AWS-based cloud project that uses Amazon EKS to deploy and manage a containerized frontend application.

The project uses Docker, Amazon ECR and Kubernetes to deploy the application. Kubernetes Deployment manages application Pods, Service distributes traffic, and Horizontal Pod Autoscaler (HPA) provides automatic scaling.
