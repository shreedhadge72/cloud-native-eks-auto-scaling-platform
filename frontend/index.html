About the Project

This project runs a containerized Nginx website on Amazon EKS. Images are built by AWS CodeBuild and stored in Amazon ECR. An Application Load Balancer exposes the site, and a Kubernetes Horizontal Pod Autoscaler adjusts the number of Pods based on CPU usage.
