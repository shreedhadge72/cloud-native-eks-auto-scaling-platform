Containerized Application on AWS

A containerized website served by Nginx and run on Amazon EKS. Traffic enters through an Application Load Balancer, and Kubernetes adjusts the number of Pods automatically based on CPU usage.

Check Live Status View on GitHub

Project Overview

What this platform demonstrates

Containerized

The website is packaged as a Docker image with Nginx, so it runs the same way on every machine and every node.

Auto-Scaling

A Horizontal Pod Autoscaler adds or removes Pods based on CPU utilization, so the application follows demand.

Load Balanced

An AWS Application Load Balancer spreads visitors across the running Pods, and Kubernetes replaces any Pod that fails.
